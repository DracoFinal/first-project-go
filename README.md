# ÍMPAR OU PAR

É um projeto de estudos escrito em Golang que me ensinou a criar uma função `main` que executa uma interação de um for range, dado a um array aonde verifica-se o resto da divisão de 2 é igual a zero. Caso seja, imprime "É par", se não, imprime "É ímpar". 

## COMO EXECUTAR

Execute o arquivo `main.go`:
```bash
go run .\main.go
```
